# 乐乐代跑 · 校园互助平台（代跑 + 二手书市）

校园互助平台，两种模式一个 App、一键切换：
- **⚡ 代跑互助**：挂单（发布代跑需求）→ 接单（同学申请）→ 线下见面交付 → 当面结算
- **📚 二手书市**：发布闲置教材（书名/课程/成色/价格）→ 同学浏览联系 → 线下当面验书付款

**平台不碰钱**：无充值、无余额、无提现、无抽成，费用完全由双方线下当面结算；金额仅作双方参考。

**数据按学校隔离**：每个学校只能看到自己学校的跑步挂单与二手书（浏览/搜索/详情/联系均限本校），跨校无法查看或联系。

## 功能总览

**客户端（底部模式条一键切换 ⚡代跑互助 / 📚二手书市，各自记忆上次停留页）**

*代跑模式（接单 / 挂单 / 进行中 + 邀请 / 我的）*
- 邮箱验证码注册登录（无密码）；学校必选（仅可选择）；性别必填（提示部分挂单有性别要求）
- 首次进入展示全流程引导（两种模式的挂单/接单/当面交易），之后可在"我的-使用指南"查看
- 挂单：选操场（管理端维护，内置集合点规则提示）+ 委托内容 + 期望报酬（每次 ≥1.99 元、上限 999.99 元，仅作双方参考）+ 周时间表选格（周日~周六 × 8~23 点共 112 格，点按/拖拽连选；按周几循环，支持跨周多次安排）+ 挂单次数（默认 5，同一时间点只安排一人，没人接自动顺延后续日期）+ 接单者性别要求
- 接单：列表（筛选操场/时间，条件本地保存直到自己改；性别不符自动隐藏）+ 排序（✨智能 / 金额 高→低 / 金额 低→高 可切换）+ 详情（含期望报酬）+ 挂单者主页
- 接单申请（按日期 + 勾选具体时间点，可多选）→ 挂单方收到消息：确认 / 拒绝（须填原因）/ 私聊（临时会话，订单结束后记录清除，支持位置、不支持图片）
- 进行中：多单并行（同时间点最多 5 单）、到达打卡、聊天、委托完成、爽约认定（15 分钟后可发起，12 小时反驳窗口）、雨天终止（双方同意或 6 小时默认同意）
- 完成互评（星级+文字，展示在对方主页）、违规举报

*书市模式（书市 / 卖书 / 消息 + 邀请 / 我的）*
- 书市浏览：搜索（书名/课程/说明，支持缩写模糊匹配：搜"线代"可命中"线性代数"）、排序（最新 / 价格 高→低 / 价格 低→高）、书籍封面、成色与课程标签，卖家昵称/学校
- 书详情：封面大图、价格/成色/课程/学校、卖家主页（完成/爽约统计）、联系卖家、举报
- 卖书：书名/课程（可空）/成色（全新~使用痕迹）/价格（0.01~999.99 元）+ 封面照（可选一张，自动压缩）+ 我的书管理（查看详情/下架/重新上架/标记已售出/换封面/未读提醒）
- 联系即入私聊（卖家-买家长期会话，支持位置消息），平台提示"线下当面验书付款"
- 消息页：书市会话列表（书已售出/下架状态标签、未读角标、铃铛通知直达回复）

*共用（邀请 / 我的）*
- 邀请：邀请码 + 好友关系（无经济奖励）
- 我的：头像（仅一张 ≤200KB 自动压缩，用于双方相认）、数据统计（完成/爽约）、历史记录、公告中心、版本更新（应用内下载安装，强制/可选）

**服务端**
- 邮箱验证码（QQ 邮箱 SMTP）、JWT、限流防刷、输入校验、封禁机制
- 订单状态机全自动化：申请超时关闭、雨天默认同意、爽约自动认定、挂单次数耗尽自动结束
- 书市：发布/搜索/上下架/售出/联系/私聊/已读/举报，书籍按 ID 存储单张封面
- 实时推送（WebSocket）
- 无平台审核：爽约/纠纷全部自助（反驳即终止，双方自行协商）

**管理后台（`http://服务器IP:8899/admin`）**
- 学校管理、操场管理（新操场立即生效）
- 公告发布（App 横幅 + 公告中心）、用户管理（搜索/封禁）、举报处理
- 书市管理：书籍列表（状态/卖家/成色/举报标记，可下架/标记已售/重新上架）+ 书市举报结案
- 规则参数（并发上限/爽约窗口/雨天时限/挂单次数等）、版本与 APK 发布

## 交易规则（平台不碰钱）

| 场景 | 处理 |
|---|---|
| 期望报酬 | 挂单时填写（1.99-999.99 元/次），列表可按金额排序；仅作双方参考 |
| 确认接单 | 直接进入进行中，无任何线上费用 |
| 完成委托 | 挂单方确认，线下当面结算 |
| 书市成交 | 买卖双方线下当面验书付款，平台仅做联系中转，不代收、不担保 |
| 雨天双方同意 | 订单终止，无费用 |
| 挂单方爽约 | 次数记入主页展示 |
| 接单方爽约 | 次数记入主页展示；被认定方 12 小时内可反驳（订单终止、不计爽约） |
| 集合时间 | 9 点 = 8:55-9:00 集合，超过 9 点视为爽约 |

## 技术选型

- **服务端**：Node.js ≥22.5 + Express + 内置 `node:sqlite`（零原生编译，低配服务器友好）+ ws（实时推送）
- **客户端**：Qt 6.5+ / QML + C++，CMake 构建，模块：Quick/QuickControls/Network/WebSockets/Positioning
- **数据库**：SQLite 单文件，WAL 模式，备份脚本自动备份
